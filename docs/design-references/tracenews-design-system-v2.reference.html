Design System

The shared component layer. Every surface imports these — no page defines its own button, toggle, popover or loading state again. Tokens are the signed Gate B palette plus a spacing scale. The logo is an existing asset referenced as a slot; this system does not define a mark.

01 · Spacing & layout

Colour and type were tokenised months ago; spacing never was, so every page picked its own padding. That is most of why the surfaces feel unrelated. 4px base. Layout constants: page 1240 · rail 230 · sidebar 320 · reading measure 66ch. Breakpoints 640 / 900 / 1180.

08 · Article card & ownership popover

★ The popover is the fix. The live tooltip uses a red dot, the party name in red and a red hover outline. Red was retired from tier bars because it reads as alarm; party-coded red also reads as taking a side. On party proximity it does both at once. Here it is anchored with a caret, built from card tokens, and proximity renders as recorded fact in body colour — with the documented-only note that makes it defensible.
