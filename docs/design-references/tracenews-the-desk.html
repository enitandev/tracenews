The Desk

Two fixes. Scope — the previous map covered the three tools that happen to exist; this maps what the console actually needs to control, every item traced to something this build promised, broke, or owes. Design — the earlier mockups looked generic because they were assembled from generic parts: sidebar, top bar, four equal stat cards, tables in boxes. TraceNews watches the press; its console should feel like the room where that happens. A broadsheet desk: masthead and dateline, one editorial sentence before any number, column rules instead of containers, enormous mono numerals as texture, one accent used twice.

Design

Console — overview

Read it top to bottom: masthead rule, dateline, then a sentence that tells you the state of the desk in words. Figures are rule-separated and unequal — the one that needs you is larger and amber. No cards. The standing column carries the live wire and the ledger, because a monitoring room shows its pulse.

Scope

What the desk controls

Every item below traces to something this build promised, broke, or owes. Amber = needed before launch. Indigo = a legal or counsel obligation, not a convenience.

Trust & compliance

The Gate 2 commitments. These are promises made to a Senior Advocate, in writing.

  • Corrections queue — intake, assign, action, SLA clockGate 2
  • Audit ledger — every staff action, named actor, reason, filterableCounsel
  • Data-subject requests — access, export, deletion under NDPANDPA
  • Counsel file — opinions, addenda, DPIA rev, sign-off status, expiryRecord
  • Consent copy versions — frozen strings, reviewedBy / reviewedAtDPIA
  • Takedown & legal requests — separate from corrections

Media intelligence data

The dataset the whole product rests on. A hand-edited tier with no record is how drift starts.

  • Outlets — registry, tier, TII score, re-score triggerNow
  • Ownership records — structure, owner, transparency, documented proximitySigned
  • Politicians — publication_status, category, positionsNow
  • Stories & clusters — view, merge, split, exclude, re-score
  • Taxonomy — categories, topics, entity tags; per-country later
  • Blog / non-tier sources — exclusion rules

Monitoring Spirit

The kill switch is a launch dependency — a live verdict with no named human able to withdraw it is indefensible.

  • Live verdicts — dismiss / reinstate with written reasonBlocks launch
  • DARK gate — the switch that keeps DARK dormant until it can passNow
  • Engine health — funnel counts, rail pass rates, per-run
  • Shadow runs — sample, results, pre-registration record
  • Rail thresholds — read-only display of what is actually live

Newsroom

The articles you raised. This is where the Bias Comparison ambition survives — human-authored, counsel from first draft.

  • Reports & analysis — draft, counsel review, publish, versionPhase 3
  • Counsel review state — on the record per pieceCumulative
  • Daily Briefing — curation and scheduling
  • Newsletter — compose, schedule, send, subscribers
  • Methodology page — versioned, editable without deploy
  • Site copy — frozen string files with sign-off fields

People & access

A shared token means the ledger records "someone with the token" — which is not the named-human guarantee we gave counsel.

  • Staff accounts — named, invite, revokeNow
  • Roles — Super Admin · Editorial · Tech · Read-only
  • Readers — account, consent state, subscription
  • Reader data — export and delete on requestNDPA
  • Subscriptions — plan, payment, refund (Paystack, naira)
  • Org seats & API keys — later

Platform health

Seven silent failures this build: empty sitemap, stale stats, dead feed, bot-path errors, hollow tests, sitemap timeout, deploys not deploying. Every one was found by accident.

  • Ingestion — live wire, per-outlet last-seen, stallsNow
  • Scorer — last run, pending, failures
  • Sitemap & indexing — URL counts, Search Console trend
  • Deploys — live commit vs main, drift alarmNow
  • Bot path — Googlebot fetch returns real content
  • Cost — API spend; an exhausted key killed the feed for 4 days
  • Tripwire log — what fired, when, acknowledged by whom

Direction

Why this isn't the same dashboard

If any of these are dropped in build, it reverts to a template. They are the design, not decoration.

Words before numbers

One Spectral sentence states the desk's condition before a single figure. Same inversion as the verdict card: say what is true, then show the evidence. Every generic dashboard opens with a stat grid and makes you do the reading.

Rules, not boxes

Nothing is a card unless it must be. Hairlines and column rules carry structure. Cards-inside-cards is the single strongest signal of a template.

Unequal figures

Four identical stat tiles say everything matters equally, which is never true. The figure that needs you is amber; the rest are ink. One accent, twice a screen.

The wire

A monitoring room shows its pulse. Live ingestion ticking in the standing column makes the console feel like an instrument that is running, not a form that is waiting.

The ledger as typeset record

Actor in weight, reason in italic Spectral. It should read like something a person can be held to — which is exactly what counsel required it to be.

Masthead and dateline

A heavy rule under the wordmark, the date set in mono. It costs nothing and it immediately reads as a press desk rather than a SaaS panel.
